This frontend UI contains the React + Vite app.

To set up `shadcn/ui` components (optional):

1. Install dependencies typically used by shadcn:

```bash
npm install class-variance-authority lucide-react tailwind-merge
```

2. Run the shadcn setup (this uses the project's preferred workflow):

```bash
npx shadcn@latest add
```

Note: `shadcn/ui` is primarily scaffolded via their CLI and custom component templates. If you want, I can attempt to run the CLI and wire up shadcn components.
